
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construir o clássico jogo de adivinhar palavras usando strings, loops, condicionais e entrada de dados do usuário em Python, praticando manipulação de strings, seleção aleatória e controle de fluxo.

## 📝 Tarefas

### 🛠️ Criar o Jogo da Forca

#### Descrição
Crie um jogo da Forca em que os jogadores adivinham letras para revelar uma palavra oculta antes de esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida
- Aceitar palpites de letras e mostrar o progresso atual no formato `_ _ _`
- Rastrear o número de tentativas incorretas restantes
- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem
- Exibir mensagens de vitória ou derrota
